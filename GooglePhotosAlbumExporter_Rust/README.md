# Google Photos Album Exporter v0.2.0

Google フォトのアルバム名と写真・動画の所属情報を、Windows PC に JSON / JSONL で保存するツールです。保存対象はファイル名、撮影日時、アルバム ID などのメタデータです。

## 初回リリースの機能

- アルバム選択画面で「すべて」または必要なアルバムだけを指定できます。
- アルバムごとに `アルバム名.jsonl` を保存します。同じファイル名になる場合に ` (2)`、` (3)` を付けます。
- 選択したアルバムをまとめた JSON と、取得件数や確認結果を記録するレポートも保存します。
- 処理件数と経過時間を表示し、一時停止・再開・中止ができます。途中保存を使って再実行できます。
- 長時間の取得は約30分ごとに専用ブラウザを切り替えて進めます。

## Windows での使い方

この配布はソースコード版です。ZIP を展開してから実行してください。初回のインストールとビルドにはインターネット接続と時間が必要です。

1. `SETUP.bat` を開きます。初回に開くメモ帳で、`config.json` の `account` に取得元の Google メールアドレス、`output_dir` に保存先を入力します。保存先は `D:/GooglePhotosAlbumBackup` のように書けます。
2. 保存してメモ帳を閉じます。SETUP は Chrome / Edge、Rust、Windows のビルド環境を確認し、不足分のインストールを開始します。案内が出たらインストーラーの手順を進めます。
3. 専用ブラウザで Google フォトにログインし、アカウントを確認します。右上の「…」メニューから「終了」を選びます。
4. `RUN.bat` を開きます。選択画面でアルバムを選び、「エクスポート」を押します。
5. 完了時に表示される保存先とレポートを確認します。アルバム別 JSONL は、実行ごとの `albums_<開始時刻>_<乱数>` フォルダに入ります。

実行中は `P` + Enter で一時停止、`R` + Enter で再開、`Q` + Enter で中止できます。

Google フォトが返す申告件数と取得件数に差がある場合や、全件性を確認できない場合は `PARTIAL` と表示します。取得できた内容と確認できなかった項目はレポートに記録します。Google フォト Web の非公開 API を利用しているため、Google 側の変更によって処理が停止する場合があります。

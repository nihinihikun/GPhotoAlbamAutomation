# 開発の引き継ぎ

既存 Google フォトからアカウント別のアルバム所属メタデータを読み出し、将来の別アカウント照合に使うツールです。出力のスキーマは v2 です。Google 側の更新があった場合は [API 調査](API_RESEARCH.md) と src/photos.js のフィールドマップから確認してください。公開実装や認証済みの最小サンプルで根拠を確認し、テストデータには実際の認証値を含めないでください。

- アカウント確認、タイムアウト、CDP の接続制約は src/browser.rs と src/photos.rs にあります。
- ページの漏れ・重複、件数、再開、確定レポートは src/export.rs と src/export/tests.rs にあります。
- 模擬 API と読み取り操作の許可一覧は tests/photos_adapter.test.cjs で検証します。
- 改修後は VERIFY.bat を実行し、[検証結果](TEST_RESULTS.md) を更新します。認証済みの最小試験は VERIFY.bat --live を使います。

将来の候補は、所有アカウントの検証に使える公式の識別子、アルバム総件数の信頼できる根拠、さらに細かなページ単位チェックポイントです。復元や移行先の写真照合は、別の作業として設計してください。

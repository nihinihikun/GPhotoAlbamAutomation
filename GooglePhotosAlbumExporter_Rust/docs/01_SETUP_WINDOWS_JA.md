# Windows 11 での導入と運用

SETUP.bat は Chrome、Edge の順でブラウザを検出し、Rust と Windows のリンカーを確認します。不足している場合は WinGet から導入を開始します。初回はインターネット接続が必要です。

1. SETUP.bat をダブルクリックし、開いた config.json を編集します。既存の設定ファイルを編集する場合はメモ帳で開きます。
2. 専用ブラウザで Google フォトにログインし、右上の Google アカウントのメールアドレスを確認します。ブラウザ右上の「…」メニューから「終了」を選びます。
3. RUN.bat を実行します。アルバム一覧から「すべて」か「選んだアルバムだけ」を選びます。後者では必要なアルバムにチェックを入れ、「エクスポート」を押します。名前で検索できます。
4. 終了時の「アルバム別 JSONL」に表示されたフォルダとレポートを確認します。アルバム別のファイルは、実行ごとのフォルダに `アルバム名.jsonl` として保存します。同名などでファイル名が重なるときは ` (2)`、` (3)` を付けます。

選択画面をキャンセルすると、書き出しを開始せず終了します。端末から画面を開かずにすべて取得する場合は、`cargo run --release --locked -- run --all --config config.json` を実行します。

実行中は約10秒ごとに、経過時間、保存済みアルバム数、処理中の写真・動画の件数、通信状況を表示します。新たに3アルバムを保存すると、実測した処理時間から残りの取得時間を見積もります。アルバムのサイズや通信状況に応じて見積もりは変わり、最後に一覧の再確認と JSON の保存が続きます。

専用ブラウザは約30分ごとに、進行中のページまたは詳細バッチを終えてから自動で切り替わります。進捗の「区間」が切り替え回数に応じて増えます。処理途中のアルバムは所属一覧を照合し、保存済みの詳細から再開します。

アルバムを選んでエクスポートを開始したあと、RUN.bat の画面で **P → Enter** を押すと一時停止、**R → Enter** で再開、**Q → Enter** で中止できます。操作は実行中の通信が戻ってから反映されます。中止すると取得済みのアルバムとレポートを保存し、次回の RUN.bat で同じアルバムを選べば途中から再開できます。結果の保存に入ったら、そのまま終了を待ってください。

## 設定

    {
      "account": "example@gmail.com",
      "output_dir": "D:/GooglePhotosAlbumBackup/test"
    }

account は対象の Google メールアドレス、output_dir は保存先です。任意項目は profile_dir（既定は chrome-profile）、browser_path（Chrome または Edge の exe）、timeout_seconds（既定の 0 は全体の制限なし。上限を設ける場合は30～86400秒）です。一時停止中は設定した上限の時間を消費しません。個々の通信にはタイムアウトがあり、一時的な失敗は最大2回再試行します。相対パスの起点は config.json のフォルダです。google_account、output_directory、従来の chrome_path も読み込めます。

フォルダを指定する場合は上記のように / で区切るか、JSON の各バックスラッシュを2つ重ねます。1つのバックスラッシュと t を並べると、JSON 上はタブになります。

## 再実行とトラブルシューティング

| 表示 | 操作 |
| --- | --- |
| output_dir が不正、OS エラー123 | config.json の保存先を確認し、区切りに / を使用する。 |
| 専用ブラウザが起動中です | SETUP.bat で開いた Chrome / Edge の右上の「…」メニューから「終了」を選んで RUN.bat を再実行する。 |
| CDP 接続前に起動プロセスが終了、または CDP の起動がタイムアウト | レポートの error に記録された終了コードや接続エラーを確認する。 |
| LOGIN_OR_ACCESS_REQUIRED / ACCOUNT_UNVERIFIED | SETUP.bat から専用ブラウザを開き、通常のログイン・再認証を行う。右上のアカウントを確認して終了する。 |
| ACCOUNT_MISMATCH | 専用ブラウザの選択アカウントと config.json を照合する。 |
| API_SCHEMA / ALBUM_ID_MISMATCH / COUNT_MISMATCH | エラーとレポートを保存し、[API 調査](API_RESEARCH.md)の該当マッピングを確認する。 |
| 申告件数より取得件数が少ないアルバムがありました | 取得できた分を保存しています。レポートの validation.album_member_count_mismatches で該当アルバムと件数を確認する。 |
| PARTIAL | レポートの validation と error を確認する。途中停止後は同じ保存先・アカウントで RUN.bat を再実行する。 |
| リンクやジャンクションを含むパス | 実体のある別フォルダを指定する。 |

完了したアルバムと最大40件単位の詳細取得結果は、保存先内のチェックポイントに保持します。再開時は現在の一覧と所属を確認し、同じ項目の詳細取得結果を再利用します。Google の認証値や継続トークンは保存対象から除外しています。

## アンインストール

専用ブラウザと GPAE を終了し、UNINSTALL.bat を実行します。画面の対象パスを確認して、専用プロファイル、ビルドフォルダ、設定のうち退避したい項目を y で承認します。復元する場合は同じ場所で元の名前に戻します。アプリのフォルダ全体を片付ける場合は、フォルダ内の書き出し済みデータを先に移動してください。

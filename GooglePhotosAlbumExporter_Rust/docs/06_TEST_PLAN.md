# 検証手順

1. 保存先の空き容量を確認する。
2. VERIFY.bat で書式、Clippy、Rust の単体・模擬 CDP、リリースビルド、Node.js の模擬 API テストを実行する。
3. テストでは複数ページ、空・同名アルバム、同名メディア、重複 ID、アカウント不一致・認証切れ、スキーマ異常、一時エラー・タイムアウト、再開、書き込み拒否、SHA-256、大量データを確認する。
4. 実アカウントで確認できる場合は、専用ブラウザで通常の認証を済ませて終了し、VERIFY.bat --live を実行する。最初の一覧ページ、先頭から最大2アルバムの最初の所属ページ、各先頭メディア1件の詳細を照会する。レポートやバックアップファイルの確定は行わない。
5. RUN.bat を使った実環境の受け入れでは、Google フォトの画面と出力のアルバム名・件数・数件の所属やファイル名を照合する。レポートで対象範囲と検証できなかった項目を確認し、Get-FileHash -Algorithm SHA256 でデータ JSON を照合する。

認証が必要な場合は SETUP.bat を利用者が実行する。試験後はテスト専用のデータを片付け、元のバックアップを保存する。
